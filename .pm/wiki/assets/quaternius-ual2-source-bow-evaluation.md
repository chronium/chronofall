## Selected source structure

The provisional proof source is only `Unreal-Godot/UAL2.glb`:

- glTF 2.0 generated by Khronos glTF Blender I/O 4.5.48;
- embedded BIN with no external resources, textures or images;
- 67 nodes, one `Armature` skin, 65 ordered joints and one `Mannequin` mesh with two primitives;
- two simple source materials, `M_Main` and `M_Joints`;
- maximum four non-zero influences through `JOINTS_0` / `WEIGHTS_0`;
- right-handed, Y-up, metre-scale data;
- bounds approximately X -0.972..0.972, Y 0.00046..1.82918, Z -0.164..0.205;
- fixed root-node axis bridge quaternion `(-0.70710677, 0, 0, 0.70710677)`.

The female mannequin contains no animations. Its supplied readme suggests retargeting because it shares the rig, but no retargeting is authorized or required for this technical proof.

## Animation inventory and root motion

Both library GLBs contain 134 animations. Exact ordinal name-set comparison against the historical UAL2 Standard snapshot found all 43 Standard clips present and no missing names; the private Source snapshot adds 91 animations.

Every inspected UAL2 clip has 195 LINEAR channels: translation, rotation and scale for every one of the 65 joints, sampled at nominal 30 Hz. The non-root-motion GLB keeps root translation at zero and root rotation constant across every sample of every animation. In the RM file, `Walk_Fwd_Loop` travels approximately 1.35 metres while the non-RM clip remains in place, confirming the supplied readme's distinction.

The six bow clips happen to have identical sampled payloads between RM and non-RM exports, but only the unsuffixed source is selected. Animation must never move the authoritative Starfall entity.

## Compatibility findings

UAL2 Source `Mannequin` is not merely name-compatible with the proven UAL1 technical mannequin:

- all 65 ordered joint names and parent indices match;
- every local rest translation, rotation and scale matches bit-for-bit;
- all 65 inverse-bind matrices match bit-for-bit;
- both mesh primitives' raw position, normal, UV, joint, weight and index accessor payloads match;
- material and embedded mesh/skin identifiers match.

This supports a strictly validated experiment-only combination of the UAL1 idle and UAL2 bow-body clips without retargeting. It does not establish a production multi-source cook.

The result does not resolve the Universal Base Character/Ranger contract. Existing evidence records 62 local-rest mismatches and 64 inverse-bind mismatches between the UAL mannequin and representative Universal Base Characters. Final dark-elf, underlayer and Ranger compatibility remains owned by Starfall selection and the later exact acquisition.
