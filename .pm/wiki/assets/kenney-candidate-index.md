# Curated Kenney Candidate Index

This is the asset-level half of the two-level Kenney catalogue. It indexes **112 directly useful candidates** from the external read-only v3.6.0 snapshot. It is a search aid, not an import manifest. Exact paths are relative to the external bundle root.

## Usefulness labels

| Label | Meaning |
|---|---|
| Immediate | Clearly useful for an already planned task. |
| Near-term | Likely useful during the first playable work. |
| Situational | Worth remembering for a specific future need. |
| Archive | Available, but no current reason to prefer it. |

Archive-only packs remain discoverable in the pack catalogue. No archive asset is placed in this directly useful shortlist.

## Selection boundary

- Quaternius remains selected for humanoid characters, the canonical/reference skeleton, animations, modular armour/clothing, and the initial `Medieval Village MegaKit[Standard]`.
- Kenney character, animation, armour, and village alternatives are available only for later owner-approved evaluation.
- Both `Medieval Weapons Pack by @Quaternius` and Kenney `Early access/Medieval Weapons` are future task-owned weapon candidates. This index selects neither.
- No candidate is copied, modified, converted, cooked, integrated, or added to a build or runtime manifest by this task.

## Search and preview guidance

- Search this page by use, consumer, pack name, or exact filename before looking outside the supplied libraries.
- Preview references are supplied source files. For 3D packs with per-asset previews, the row points to the matching image; older OBJ packs use the supplied pack overview.
- Model dimensions are raw source-axis extents, not metres. They are useful for comparing assets within a pack but do not establish ChronoFall scale.
- Audio duration is measured from the supplied OGG. It does not imply approved loudness, looping, spatialization, or trigger ownership.
- Later import tasks must reread the source licence and record v3.6.0, pack/version/Early Access status, original relative path, copied files, official source, CC0 evidence, modifications, intended consumer, and compilation non-redistribution confirmation.
