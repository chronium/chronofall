# ChronoFall Project History

This directory preserves a small, curated timeline of visual milestones that are useful for understanding how ChronoFall evolved. It is not a dump of generated build artifacts.

Each dated entry should contain:

- an owner-selected image or similarly compact artifact;
- the owning canonical PM task or wiki reference;
- exact source and licence provenance;
- a short explanation of what the artifact proves;
- reproduction or generation details when useful;
- a content hash for the preserved file.

Raw captures, intermediate conversions, test output, and bulk generated evidence remain under the ignored `artifacts/` directory. A file moves here only when it is deliberately selected as durable project history.

The dated, repository-relative layout is intended to remain stable so a future PM wiki image/timeline feature can reference these artifacts directly.
